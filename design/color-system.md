# Color system: polar night

| Token | Hex | Where |
|---|---|---|
| Polar Night | #07121B | Page, canvas at night, panels |
| Ice | #D9F5F6 | Text, thick ice, the whiteout |
| Glacial Blue | #7CC7D9 | Rules, mid-thickness ice, labels |
| Deep Crevasse | #0B5466 | Thin ice, ice bodies, open-water edge |
| Aurora Green | #78E6B5 | Routes, primary actions, the current selection |
| Aurora Violet | #9F8BEA | Risk, the storm's edge, the second route |

Risk runs from Ice to Aurora Violet; danger crystallises, it never flashes red.
